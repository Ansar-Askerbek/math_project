Это проект по математике 
Данная идея данного проекта в том чтобы проанализировать с помощью метода Рунге-Кутты 4-порядка прогрешность при решении дифференциальной системы. В данном проекте вместо использования привычного модуля integrate.solve_ivp от scipy я написал вручную логику построение и вычесление решений для этой системы.
