Это проект по математике 
Данная идея данного проекта в том чтобы проанализировать с помощью метода Рунге-Кутты 4-порядка прогрешность при решении дифференциальной системы. В данном проекте вместо использования привычного модуля integrate.solve_ivp от scipy я написал вручную логику построение и вычесление решений для этой системы. Далее детальный анализ данного проекта

```markdown
# Математический проект: анализ SIR-модели

## Описание

Данный проект посвящён моделированию распространения инфекции с использованием SIR-модели и сравнению численных методов решения дифференциальных уравнений.

В проекте сравниваются метод Эйлера и метод Рунге–Кутты четвёртого порядка (RK4). Для оценки точности используется эталонное решение, полученное методом RK4 с очень маленьким шагом `dt = 0.0001`. Затем вычисляются среднеквадратичная ошибка (MSE) и средняя относительная погрешность приближённых решений.

## Используемые технологии

- **Язык программирования:** Python
- **NumPy** — для численных вычислений и работы с массивами
- **Matplotlib** — для построения графиков

## Математическая модель

SIR-модель разделяет население на три группы:

- `S` — восприимчивые к инфекции люди;
- `I` — инфицированные люди;
- `R` — выздоровевшие люди.

Модель описывается системой дифференциальных уравнений:

```text
dS/dt = -βSI/N

dI/dt = βSI/N - γI

dR/dt = γI
```

где:

- `N` — общая численность населения;
- `β` — коэффициент передачи инфекции;
- `γ` — коэффициент выздоровления.

Проект также поддерживает несколько вариантов изменения коэффициента передачи инфекции:

- `constant` — постоянный коэффициент;
- `quarantine` — постепенное снижение коэффициента;
- `seasonal` — сезонное изменение коэффициента.

## Принцип работы

1. Создаётся эталонное решение SIR-модели с помощью метода RK4 и очень маленького шага.
2. Модель решается методом Эйлера с шагом `dt = 1.0`.
3. Модель решается методом RK4 с шагом `dt = 1.0`.
4. Полученные решения сравниваются с эталонным решением.
5. Рассчитываются:
   - среднеквадратичная ошибка (MSE);
   - средняя относительная погрешность.
6. Строятся графики численности восприимчивых, инфицированных и выздоровевших людей.

## Запуск

Для запуска основного эксперимента выполните:

```bash
python main.py
```

Программа выведет значения ошибок в консоль и откроет график с результатами сравнения методов Эйлера и RK4.

Для запуска простого тестового графика выполните:

```bash
python test_plot.py
```
